# ZenPost - Social Media Management Platform

A modern React-based social media scheduling platform with a dark theme and purple accent colors.

## Features

- Modern dark theme with purple gradient accents
- Fully responsive design
- Built with React + Vite for fast development
- Complete routing with React Router
- Smooth animations and transitions

## Pages

### Public Pages
- **Landing Page** (/) - Hero section, features, testimonials, and CTA
- **Pricing** (/pricing) - Pricing plans and comparison
- **Features** (/features) - Detailed feature showcase
- **About** (/about) - Company information
- **Contact** (/contact) - Contact form
- **Blog** (/blog) - Blog posts and articles
- **Documentation** (/docs) - Product documentation
- **Privacy Policy** (/privacy) - Privacy information
- **Terms of Service** (/terms) - Terms and conditions

### Authentication Pages
- **Sign Up** (/signup) - User registration with social auth options
- **Sign In** (/login) - User login with remember me option
- **Forgot Password** (/forgot-password) - Password reset request
- **Reset Password** (/reset-password) - Set new password with validation

## Installation

1. Install dependencies:
\`\`\`bash
npm install
\`\`\`

2. Run the development server:
\`\`\`bash
npm run dev
\`\`\`

3. Open your browser at http://localhost:3000

## Build for Production

\`\`\`bash
npm run build
\`\`\`
